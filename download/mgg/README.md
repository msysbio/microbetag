For running `microbetag` through the MGG app, you may use either: 

- `testAbund.tsv` **or**
- `vitAbund.tsv`


To run it using an abundance table **and** a metadata file
- `testAbund.tsv`
- `metadata.tsv`


To run it using an abundance table **and** a network already available:
- `vitAbund.tsv`
- `edgelist.tsv`


The `metadata.tsv` file will **not** work with the `vitAbund.tsv` since the number of samples is different between the two files.
